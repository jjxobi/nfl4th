# Frontend

The Astro static site for the NFL 4th Down Coach Tendency Predictor: a
situation predictor and a coach tendency browser, consuming the FastAPI
backend in `../api`.

Run it locally with `npm install && npm run dev`. Requires `PUBLIC_API_URL`
set in `.env` (copy `.env.example`), pointing at a running backend. See the
root README's Frontend section for more detail.
